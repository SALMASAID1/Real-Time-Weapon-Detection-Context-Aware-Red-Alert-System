# Task 5.2: Real-time Dashboard (FastAPI & React)

## Description
Build a professional, modern monitoring dashboard using React for the frontend and FastAPI for the backend to handle live threat detection and logging.

## Details
1. **Backend**: FastAPI for handling video streams, inference results, and Grad-CAM data via WebSockets.
2. **Frontend**: React application (e.g., using Vite) for:
   - High-performance real-time video rendering.
   - Interactive threat history table.
   - Dynamic heatmaps (Grad-CAM overlays).
   - Responsive UI for desktop and mobile monitoring.
3. **Communication**: Use WebSockets for low-latency data transfer between the AI engine and the UI.
