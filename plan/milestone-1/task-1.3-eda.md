# Task 1.3: Exploratory Data Analysis (EDA)

## Description
Perform a deep dive into the dataset using `notebooks/Phase1_EDA.ipynb` to understand class distribution, image quality, and bounding box statistics.

## Details
1. **Class Distribution**: Plot histograms of class counts to identify potential imbalances.
2. **Bounding Box Analysis**: Calculate the average size of bounding boxes relative to image resolution. This helps determine if SAHI (Slicing Aided Hyper Inference) is necessary for small objects.
3. **Visual Inspection**: Display sample images with ground truth boxes to verify annotation accuracy.
