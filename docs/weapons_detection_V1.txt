================================================================================

1  Introduction

This project aims to develop a state-of-the-art surveillance system that identifies firearms
and bladed weapons in real-time. Moving beyond standard object detection, this system
focuses on Contextual Intelligence to distinguish between benign objects (e.g., smart-
phones, tools) and actual threats, specifically optimized for high-angle CCTV environ-
ments.

================================================================================

2  Phase 1: Advanced Data Engineering

The foundation of the project relies on a robust, multi-source dataset to ensure high
generalization.

  • Data Aggregation: Merging the University of Granada (SOHAS), Unidpro, and
    Simuletic Synthetic datasets to reach a target of ~40,000 images.

  • Hard Negative Mining: Integrating 5,000+ images of "confuser" objects (um-
    brellas, drills, wallets) to minimize False Positive Rates (FPR).

  • Synthetic Injection: Using GANs or Simuletic data to simulate adverse weather
    and low-light conditions.

================================================================================

3  Phase 2: Slicing Aided Hyper Inference (SAHI)

Detecting small weapons in 4K surveillance footage is a major challenge. We will imple-
ment SAHI to maintain resolution:

  • Instead of resizing images to 640 x 640, the system will perform tiled inference.

  • Overlapping patches are analyzed individually, and results are merged using Non-
    Maximum Suppression (NMS).

================================================================================

4  Phase 3: Hybrid Model Architecture

To achieve superior performance over standard CNNs, we propose a hybrid Backbone-
Neck structure:

  • Backbone: YOLOv11/v12 for rapid local feature extraction.

  • Neck/Attention: Integration of a Swin Transformer block to capture global
    spatial dependencies.

  • Optimization (Focal Loss): To handle class imbalance, we utilize Focal Loss:

        FL(p_t) = -alpha_t * (1 - p_t)^gamma * log(p_t)          (1)

    Where gamma is the focusing parameter that down-weights easy examples.

================================================================================

5  Phase 4: Threat Logic and Proximity Analysis

An advanced system must understand the relationship between the person and the object.

  • Hand-Object Interaction: Parallel detection of human hands and weapons.

  • Threat Scoring: A logical layer that triggers high-priority alerts only when the
    Intersection over Union (IoU) between a "Hand" box and a "Weapon" box exceeds
    a defined threshold.

================================================================================

6  Phase 5: Explainability (XAI)

To ensure the model is not biased by background elements, we implement Grad-CAM
(Gradient-weighted Class Activation Mapping). This generates heatmaps indicating the
specific pixels (e.g., the trigger or barrel) that influenced the classification.

================================================================================

7  Phase 6: Deployment and Optimization

  • Inference Engine: Quantization of the model to TensorRT or OpenVINO for
    real-time performance (>30 FPS).

  • Dashboard: A FastAPI backend with a Streamlit frontend for live monitoring
    and threat logging.

9  Success Metrics

The project will be evaluated based on:

  1. mAP@0.5:0.95: Mean Average Precision across various IoU thresholds.

  2. Latency: Inference time per frame (ms).

  3. FPR: Reduction in false alarms caused by handheld electronics.
