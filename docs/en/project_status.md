## ✅ Completed Milestones

### Milestone 1: Data Engineering ✅
*   Unified 50,967 images across 3 classes: `[Weapon, Person, Confuser]`.
*   EDA analysis revealed 36.2% small-object bottleneck, informed Swin Neck architecture.
*   Synthetic augmentation (rain, fog, low-light) for 24/7 robustness.

### Milestone 2: Hybrid Model Architecture ✅
*   **YOLOBackbone** (`yolo11m.pt`): Manual layer-by-layer forward pass at indices `[4, 6, 10]` for DataParallel-safe P3/P4/P5 extraction.
*   **SwinNeck**: timm SwinTransformerBlock (window_size=7, 2 blocks) with FPN lateral connections.
*   **DetectionHead**: Decoupled cls/reg/obj branches, Focal Loss (γ=2.0, α=0.25), DFL regression (reg_max=16), CIoU box loss.
*   **Training Pipeline**: 7 iterations, final v7 with differential LR and Cosine Annealing.

### Milestone 3: Inference Intelligence & XAI ✅
*   **SAHI Pipeline**: Tiled inference (640×640 tiles, 20% overlap) with cross-tile NMS merge.
*   **Threat Scoring**: Composite formula `S = 0.3×conf + 0.5×proximity + 0.2×persistence` with HIGH/LOW thresholds.
*   **IoU Calculator**: GIoU mode for proximity detection, pairwise hand-weapon matrix.
*   **Grad-CAM**: Targets `neck.p4_proj_out` layer, returns JPEG bytes for WebSocket delivery.
*   **Overlay Renderer**: INFERNO colormap compositing, bbox annotation, JPEG encoding.

### Milestone 4: Multimodal Alerting & Dashboard ✅
*   **AlertDispatcher**: Telegram (async), Pygame audio (3-loop play), JSONL event logging, 30s cooldown deduplication.
*   **InferenceEngine**: Dual-cadence (SAHI every N + lightweight), two-stream (Weapon + Hand), asyncio.Queue broadcasting.
*   **FastAPI Backend**: WebSocket `/ws/stream/{camera_id}`, REST `/api/threats` (CRUD), `/api/settings` (live-apply).
*   **React Dashboard**: LiveMonitor (VideoCanvas + side panel), ThreatHistory (paginated + filtered), Settings (ThresholdPanel).
